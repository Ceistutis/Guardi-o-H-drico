# Documentação técnica

Guardar aqui os documentos técnicos que devem acompanhar as versões do código:

- Arquitetura e fluxos de dados.
- Diagrama elétrico/hidráulico e pinagem.
- Contrato de telemetria e comandos.
- Procedimentos de calibração e testes.

A wiki no Notion concentra decisões, compras, atualizações, fotos, resultados e material para o relatório. O ClickUp concentra tarefas e sprints.

Referenciar versões ou commits ao registrar evidências de um teste.
