# Firmware do ESP32

Espaço para leitura dos sensores, calibração, lógica local, acionamento da válvula e telemetria.

Proposta inicial: ESP32 com Arduino/C++. Placa, bibliotecas, ferramenta de build, pinagem e circuito de acionamento ainda serão definidos.

Ao iniciar a implementação, registrar aqui:

- Placa e versões das ferramentas/bibliotecas.
- Diagrama e pinagem da montagem utilizada.
- Como configurar, compilar e gravar o firmware.
- Contrato de dados e comandos.
- Como executar e registrar a calibração e os testes.

Não há firmware executável nesta estrutura inicial.
